# Portfolio Setup Project

## Tools Installed

- **Cursor IDE** — AI-powered code editor (https://cursor.com/)
- **Claude Code** — Cursor extension for AI-assisted coding
- **Codex** — Cursor extension for code generation

## Steps Completed

1. Downloaded and installed Cursor IDE from https://cursor.com/
2. Signed in to Cursor using GitHub account
3. Installed the Claude Code extension from the Extensions marketplace
4. Logged in to Claude Code
5. Installed the Codex extension from the Extensions marketplace
6. Logged in to Codex
7. Created a public GitHub repository
8. Cloned the repository locally and opened it in Cursor
9. Created this README.md file
10. Committed and pushed all changes to GitHub

## Issues Encountered


I did not face any major technical issues during setup. The main learning curve was understanding the GitHub workflow creating a repository, opening it in Cursor, committing changes, and pushing the README.md file successfully.

To solve this, I referred to GitHub and Cursor tutorials and followed the process step by step until the README appeared correctly in the public repository.
